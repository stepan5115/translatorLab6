## Тестирование
для сборки проекта и запуска тестов достаточно запустить скрипт командой
```bash
./test_runner.sh
```
Далее вы увидите как проект собирается, а затем детальные результаты валидных и невалидных тестов
## Сборка и запуск
конкретный синтаксис сборки и запуска
```bash
make all
make run INPUT_FILE=<file_name>
```
